## 1. Base Layout (`base.html`)

Единый layout для всех страниц приложения.

### Структура

```
┌──────────────────────────────────────────────────────────────┐
│  ☰  AI Writer Lab       [Export ▾]  [🌙/☀️]  [RU/EN]  [⚙]    │
├────────┬─────────────────────────────────────────────────────┤
│        │                                                     │
│ Sidebar│              Main Content Area                      │
│        │                                                     │
│ Home   │  Breadcrumbs: Проекты > "Тёмный лес" > Гл.1 > Сц.3│
│ ───────│                                                     │
│ Project│              (slot for page content)                │
│  Wizard│                                                     │
│  Work- │                                                     │
│  space │                                                     │
│  Analyt│                                                     │
│ ───────│                                                     │
│ Setting│                                                     │
│        │                                                     │
└────────┴─────────────────────────────────────────────────────┘
```

### Sidebar
- Сворачиваемый (кнопка ☰ или hover)
- Секции:
  - **Навигация:** Домой, Настройки
  - **Текущий проект** (появляется при входе в проект):
    - Story Wizard
    - Story Workspace (дерево глав/сцен — только в Left Panel Workspace)
    - Аналитика
- Нижняя часть: версия приложения, ссылка на документацию

> Дерево глав и сцен **не** дублируется в sidebar — оно находится
> только в Left Panel Story Workspace (см. секцию 4).

### Top Bar
- Логотип / название
- **[Export ▾]** — кнопка быстрого экспорта книги (dropdown: MD / PDF / EPUB). Видна когда открыт проект.
- Переключатель темы (тёмная/светлая)
- Переключатель языка (RU/EN)
- Настройки (⚙)

### Left Panel — дерево глав и сцен

Основной инструмент навигации по книге. Иерархическое дерево: **Книга > Главы > Сцены**.

```
📖 Тёмный лес
├─ ▼ Глава 1: Начало          [3 сцены, 4200 слов]
│  ├─ 🟢 1. Прибытие              1200 сл  👤Анна
│  ├─ 🟡 2. Первая встреча          980 сл  👤Анна 👤Дмитрий
│  └─ 🔴 3. Разговор                  0 сл
├─ ▼ Глава 2: Конфликт        [2 сцены, 1500 слов]
│  ├─ 🟡 4. Предательство          1500 сл  👤Дмитрий
│  └─ 🔴 5. Погоня                    0 сл
├─ [+ Сцена]  [+ Глава]
└─ [🤖 Сгруппировать в главы]
```

**Элементы каждой сцены:**
- Цветовой индикатор статуса: 🔴 Пусто / 🟡 Черновик / 🟢 Отредактировано / 🔵 HQ
- Порядковый номер + название
- Количество слов
- Иконки основных персонажей сцены

**Элементы каждой главы:**
- Название (редактируемое)
- Сводка: кол-во сцен, общее кол-во слов
- Collapsible (▼/▶)

**Действия:**
- **Drag & drop** сцен внутри главы и между главами (SortableJS)
- **[+ Сцена]** — добавляет сцену (в текущую главу или без главы)
- **[+ Глава]** — создаёт новую главу
- **[🤖 Сгруппировать в главы]** — AI предлагает разбивку плоского списка сцен на главы
- Фильтр по персонажу / акту
- Контекстное меню: Переименовать, Удалить, Переместить в главу...

**Организация глав:**
- Можно работать без глав (плоский список сцен) — удобно в начале работы
- Главы создаются вручную или AI предлагает разбивку
- Сцены перетаскиваются между главами
- Мини-прогресс внизу панели: полоска из цветных сегментов (по статусам сцен)

### Center Panel — редактор

- Breadcrumbs вверху: `Глава N > Сцена M: Название`
- Отдельные кнопки **Save** (сохраняет текст) и **Generate** (вызывает AI)
- Word count + reading time (внизу)
- Autosave индикатор ("Сохранено", "Сохранение...")
- Кнопка **[Illustrate]** — открывает Illustration sliding panel (см. ниже)
- Кнопка **[Insert img]** — вставляет маркер иллюстрации `![описание](image.png)` в позицию курсора (выбор из загруженных картинок)
- Поддержка inline-маркеров иллюстраций: `![описание](image.png)` отображается как превью картинки в редакторе

### Right Panel — AI Co-Author (Chat)

Правая панель целиком занята AI-чатом. Без вкладок — единый поток.

Подробная спецификация чата: [AI_CHAT_AND_CONTEXT.md](AI_CHAT_AND_CONTEXT.md).

Ключевые элементы:
- **Task bar**: название текущей задачи, [+ New Task], [History]
- **Context bar**: компактный/раскрываемый, кол-во токенов, прогресс-бар
- **Chat area**: сообщения с @-ссылками-badges, streaming
- **Input area**: textarea с @ автокомплитом
- **Quick actions**: контекстные кнопки:
  - Если сцена пустая: [Generate scene] [Suggest variants]
  - Если сцена написана: [Continue] [Add dialogue] [Describe setting]
  - Всегда: **[Review]**, **[Illustrate]**

**Review** — запускается через Quick Action. Результат отображается как форматированное AI-сообщение в чате:
- Score badge (цветной: 🟢 8+, 🟡 6-8, 🔴 <6)
- Список issues
- Кнопки [Apply Fix] при каждом issue

**Illustration** — Quick Action **[Illustrate]** открывает **sliding panel** (overlay поверх правой панели). См. [ILLUSTRATION_PROMPT_GENERATOR.md](ILLUSTRATION_PROMPT_GENERATOR.md).

## 5. Chapter Editor (переработанный)

Chapter Editor показывает **все сцены главы последовательно** — как единый текст с разделителями.

### Layout

```
┌──────────────────────────────────┬───────────┐
│                                  │           │
│  Глава 1: Начало                 │ Context   │
│  ────────────────                │           │
│                                  │ Summary   │
│  --- Сцена 1: Прибытие ---      │ prev ch.  │
│  [Текст сцены 1]                │           │
│                                  │ NarrSpec  │
│  --- Сцена 2: Первая встреча --- │ refs      │
│  [Текст сцены 2]                │           │
│                                  │ Versions  │
│  --- Сцена 3: Разговор ---      │  v3 [↺]   │
│  [Текст сцены 3 (пусто)]        │  v2 [↺]   │
│                                  │  v1 [↺]   │
│  ─────────────────────────────── │           │
│  Слов: 4,200  ~17 мин           │ [Diff v2  │
│                                  │  vs v3]   │
│  [Review] [Produce HQ] [Export] │           │
│                                  │           │
└──────────────────────────────────┴───────────┘
```

### Назначение

Chapter Editor — режим **чтения и ревью** главы целиком:
- Редактирование отдельных сцен — в Story Workspace
- Здесь: просмотр собранной главы, ревью, экспорт одной главы
- Клик на заголовок сцены переходит в Workspace с фокусом на этой сцене

### Элементы
- **Context sidebar**: summary предыдущих глав, ключевые элементы NarrativeSpec
- **Diff view**: выбрать 2 версии → показать различия (inline или side-by-side)
- **Formatted review** (через AI Chat): Score badge, список issues, кнопки Apply Fix
- **Progress bar** для Produce HQ: "Iteration 2/3, Score: 7.2..."
- **Export preview**: как будет выглядеть глава при экспорте (с иллюстрациями)
