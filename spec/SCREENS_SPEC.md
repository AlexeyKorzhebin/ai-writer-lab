### Sidebar
- Сворачиваемый (кнопка ☰ или hover)
- Секции:
  - **Навигация:** Домой, Настройки
  - **Текущий проект** (появляется при входе в проект):
    - Story Wizard
    - Story Workspace
    - Главы (список)
    - Аналитика
    - Экспорт
- Нижняя часть: версия приложения, ссылка на документацию

### Top Bar
- Логотип / название
- Переключатель темы (тёмная/светлая)
- Переключатель языка (RU/EN)
- Настройки (⚙)

### Шаги

```
[0. Quick Start] → [1. Idea] → [2. World] → [3. Characters] → [4. Structure] → [5. Review]
```

### Step 0 — Quick Start (НОВЫЙ)

```
┌─────────────────────────────────────────────┐
│  Как вы хотите начать?                      │
│                                             │
│  ┌───────────────┐  ┌───────────────┐       │

│  └───────────────┘  └───────────────┘       │

│  [А. С. Пушкин                        ▾]    │
│                                             │
│  Язык произведения:                         │
│  ○ Русский  ○ English                       │
│                                             │
│                          [Далее →]          │
└─────────────────────────────────────────────┘
```

### Step 1 — Idea (улучшения)

Добавить:
- Кнопка [🤖 Предложить логлайн] — AI генерирует на основе жанра
- Кнопка [🤖 Развить конфликт] — AI расширяет описание конфликта

### Step 3 — Characters (улучшения)

Добавить:
- Поле **Внешность** (для иллюстраций)
- Поле **Манера речи**
- Кнопка [🤖 Предложить персонажа]
- Простая визуализация связей (список: "Анна → враждует с → Дмитрий")

### Step 4 — Structure (улучшения)

Добавить:
- Визуальная timeline:
```
  ○────────●────────────●──────────●────────○
  Начало   Поворот 1    Кульминация Поворот 2 Финал
```
- Кнопка [🤖 Сгенерировать поворотные точки]

### Step 5 — Review (улучшения)

Добавить:
- AI-валидация с предупреждениями:
  - ⚠️ "Не задан антагонист"
  - ⚠️ "Кульминация не описана"
  - ✅ "Все основные элементы на месте"

## 4. Story Workspace (переработанный)

### Layout

```
┌────────┬─────────────────────────────┬──────────┐
│  Left  │        Center               │  Right   │
│  Panel │        Editor               │  Panel   │
│ 280px  │        flex-1               │  360px   │
│        │                             │          │
│ Charact│  Scene Title                │ AI       │
│ World  │  ─────────                  │ Co-Author│
│ Scenes │                             │          │
│ (drag) │  [Text editor area]         │ [Gener.] │
│        │                             │ [Variants│
│        │                             │ [Review] │
│        │  Words: 1,250  ~5 min read  │ [Illust.]│
│        │                             │          │
│        │  [Save] [Generate] [Illust.]│ Chat:    │
│        │                             │ [input]  │
└────────┴─────────────────────────────┴──────────┘
```

### Left Panel — изменения
- **Drag & drop** сцен (SortableJS)
- Цветовые индикаторы:
  - 🔴 Пусто (нет контента)
  - 🟡 Черновик (сгенерировано)
  - 🟢 Отредактировано
  - 🔵 HQ (прошло orchestration)
- Фильтр по персонажу / акту
- Мини-прогресс: полоска из цветных сегментов

### Center Panel — изменения
- Отдельные кнопки Save (сохраняет текст) и Generate (вызывает AI)
- Word count + reading time (внизу)
- Autosave индикатор ("Сохранено", "Сохранение...")
- Кнопка **Illustrate** — открывает Illustration Prompt Generator

### Right Panel — изменения
- Вкладки: **AI Co-Author** | **Review** | **Illustration**
- AI Co-Author:
  - Generate Scene
  - Suggest 3 Variants
  - Chat input: "сделай диалог длиннее"
- Review:
  - Score badge (цветной)
  - Список issues
  - Кнопки "Apply Fix"
- Illustration:
  - Встроенная панель Illustration Prompt Generator
  - История промптов для сцены

## 5. Chapter Editor (переработанный)

### Layout

```
┌──────────────────────────────────┬───────────┐
│                                  │           │
│  Chapter Title                   │ Context   │
│  ─────────────                   │           │
│                                  │ Summary   │
│  [Text editor]                   │ prev ch.  │
│                                  │           │
│                                  │ Narrative │
│                                  │ Spec ref  │
│                                  │           │
│  [Save] [Regen] [Review]        │ Versions  │
│  [Apply] [Produce HQ]           │  v3 [↺]   │
│                                  │  v2 [↺]   │
│  ─────────── Review ──────────── │  v1 [↺]   │
│  Score: [8.5] ✅ No major issues │           │
│  • Сюжетная линия логична        │ [Diff v2  │
│  • Стиль соответствует           │  vs v3]   │
│  ⚠ Диалог слишком длинный        │           │
│    [Apply Fix]                   │           │
│                                  │           │
└──────────────────────────────────┴───────────┘
```

### Новые элементы
- **Context sidebar**: summary предыдущих глав, ключевые элементы NarrativeSpec
- **Diff view**: выбрать 2 версии → показать различия (inline или side-by-side)
- **Formatted review**: Score badge, список issues, кнопки Apply Fix
- **Progress bar** для Produce HQ: "Iteration 2/3, Score: 7.2..."
