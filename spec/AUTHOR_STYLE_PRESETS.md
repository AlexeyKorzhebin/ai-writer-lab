# Author Style Presets — Спецификация

Дата: 2026-03-20
Статус: Draft

---

## 1. Концепция

Пресеты авторских стилей — готовые текстовые описания стилистики известных писателей, которые используются как системные промпты при генерации текста. Пользователь выбирает пресет, может его отредактировать, и стиль применяется ко всем операциям генерации.

---

## 2. Формат хранения

Файл: `app/data/author_presets.yaml`

```yaml
presets:
  - key: pushkin
    name: "А. С. Пушкин"
    language: ru
    era: "XIX век, Золотой век русской литературы"
    description: "Лёгкий, ироничный стиль. Ритмичная проза."
    style_prompt: |
      Пиши в стиле Александра Сергеевича Пушкина.
      Характерные черты:
      - Лёгкий, изящный слог с ироничными интонациями
      - Ритмичная проза, близкая к поэзии
      - Точные, ёмкие эпитеты без излишеств
      - Живые, естественные диалоги
      - Сочетание возвышенного и бытового
      - Тонкая ирония и самоирония
      - Лаконичные описания природы, но выразительные
      - Психологизм через действия, а не через рефлексию
      Избегай: тяжеловесных конструкций, избыточных описаний,
      современного сленга, канцелярита.
    sample: |
      Дубровский молча и неподвижно стоял у дверей, пока старик
      не проехал мимо. Потом он повернулся и медленно пошёл прочь
      по аллее, не оглядываясь.

  - key: tolstoy
    name: "Л. Н. Толстой"
    language: ru
    era: "XIX век, русский реализм"
    description: "Глубокий психологизм. Длинные периоды."
    style_prompt: |
      Пиши в стиле Льва Николаевича Толстого.
      Характерные черты:
      - Длинные, сложные предложения с множеством придаточных
      - Глубокий психологический анализ через внутренний монолог
      - Детальные описания внешности, жестов, выражений лица
      - «Диалектика души» — показ противоречивых чувств одновременно
      - Подробные описания быта и обстановки
      - Философские отступления, вплетённые в повествование
      - Контраст между внешним поведением и внутренним состоянием
      - Множество точек зрения на одно событие
      Избегай: простых коротких предложений, поверхностных описаний,
      однозначных оценок персонажей.
    sample: |
      Князь Андрей, войдя в кабинет отца, застал его за работой
      и, хотя он и знал, что отец при виде его сделает вид,
      что недоволен его приездом, — почувствовал, что и отец рад,
      и что радость эта, хотя и скрываемая, тронула его.

  - key: tolkien
    name: "Дж. Р. Р. Толкиен"
    language: en
    era: "XX век, эпическое фэнтези"
    description: "Эпический стиль. Архаичная лексика. Мифопоэтика."
    style_prompt: |
      Пиши в стиле Дж. Р. Р. Толкиена.
      Характерные черты:
      - Эпический, возвышенный тон повествования
      - Архаичная лексика и обороты («ибо», «ныне», «сей»)
      - Подробные описания ландшафтов, природы, архитектуры
      - Мифопоэтический стиль: мир как живое существо
      - Песни, стихи и пророчества, вплетённые в текст
      - Чёткое разделение добра и зла (с нюансами)
      - Длинные путешествия как метафора внутреннего пути
      - Чувство древности, глубины истории мира
      - Меланхолия уходящей эпохи
      Избегай: современного сленга, циничного тона, бытовых деталей
      без символического значения.
    sample: |
      Горы поднимались перед ними, и солнце окрашивало их вершины
      в золото и пурпур. Но тень уже ложилась на долину, и в той
      тени что-то ждало — древнее и терпеливое, как сама земля.

  - key: chekhov
    name: "А. П. Чехов"
    language: ru
    era: "XIX–XX век, русский реализм"
    description: "Лаконичность. Подтекст. Деталь вместо описания."
    style_prompt: |
      Пиши в стиле Антона Павловича Чехова.
      Характерные черты:
      - Лаконичность: «Краткость — сестра таланта»
      - Подтекст важнее текста: главное не сказано прямо
      - Одна точная деталь вместо длинного описания
      - Бытовые диалоги, за которыми скрывается драма
      - Отсутствие моральных оценок — автор показывает, не судит
      - Грусть и юмор одновременно
      - Незаконченность: открытые финалы
      - Атмосфера важнее сюжета
      Избегай: пафоса, прямых моральных выводов, длинных монологов,
      чрезмерной экспрессии.
    sample: |
      Доктор вымыл руки, постоял у окна. На дворе было тихо.
      Где-то далеко играли на гармонике. Он подумал, что надо бы
      уехать, но не двинулся с места.

  - key: stephen_king
    name: "Стивен Кинг"
    language: en
    era: "XX–XXI век, хоррор / триллер"
    description: "Разговорный стиль. Внутренний голос. Саспенс."
    style_prompt: |
      Пиши в стиле Стивена Кинга.
      Характерные черты:
      - Разговорный, живой язык, близкий к устной речи
      - Сильный внутренний голос персонажа (поток сознания)
      - Обычные люди в необычных обстоятельствах
      - Медленное нарастание тревоги и саспенса
      - Детальные описания повседневного быта (создают контраст с ужасом)
      - Курсив для мыслей персонажа
      - Отсылки к поп-культуре
      - Неожиданные вспышки насилия или странности
      - Маленькие города Америки как место действия
      Избегай: академического языка, сухого изложения, отсутствия
      эмоций, стерильности.
    sample: |
      Он шёл по коридору, и каждый шаг отзывался эхом.
      Не оборачивайся, подумал он. Что бы ни было за спиной —
      не оборачивайся. Но руки уже тряслись, и он знал — он знал —
      что обернётся.

  - key: dostoevsky
    name: "Ф. М. Достоевский"
    language: ru
    era: "XIX век, психологический реализм"
    description: "Надрыв. Экзистенциальные конфликты. Полифония."
    style_prompt: |
      Пиши в стиле Фёдора Михайловича Достоевского.
      Характерные черты:
      - Надрывная, напряжённая интонация
      - Полифония: каждый персонаж — полноценный голос с философией
      - Длинные диалоги-споры на экзистенциальные темы
      - Лихорадочный внутренний монолог
      - Тема двойничества, раздвоения личности
      - Петербург как персонаж: давящий, серый, болезненный
      - Крайности: святость и грех рядом
      - Детальное описание физических состояний (лихорадка, бред, боль)
      Избегай: спокойного повествования, лёгкого тона, поверхностных
      конфликтов, быстрых развязок.
    sample: |
      Он остановился посреди улицы. Сердце билось так, что,
      казалось, его слышат прохожие. «Я ведь не сделаю этого, —
      подумал он, — я ведь ни за что…» Но ноги уже несли его

      - Магический реализм: чудесное как обыденное
      - Длинные, текучие предложения без пауз
      - Циклическое восприятие времени
      - Изобилие деталей: запахи, цвета, текстуры
      - Семейные саги, поколения
```

## 3. UI-компоненты

### 3.1 В Story Wizard (Step 0 или Step 1)

```
┌─────────────────────────────────────────┐
│  Author Style                           │
│                                         │
│  [А. С. Пушкин            ▾]           │
│                                         │
│  Preview:                               │
│  ┌───────────────────────────────────┐  │
│  │ "Дубровский молча и неподвижно   │  │
│  │  стоял у дверей, пока старик     │  │
│  │  не проехал мимо..."             │  │
│  └───────────────────────────────────┘  │
│                                         │
│  Style description: (editable)          │
│  ┌───────────────────────────────────┐  │
│  │ Лёгкий, изящный слог с           │  │
│  │ ироничными интонациями...        │  │
│  └───────────────────────────────────┘  │
│                                         │
│  [Generate Sample in This Style]        │
└─────────────────────────────────────────┘
```

### 3.2 В Project Settings

- Dropdown с пресетами
- Текстовое поле `author_style` предзаполняется `style_prompt` выбранного пресета
- Кнопка "Generate Sample" — AI генерирует пример текста в выбранном стиле на основе logline проекта

### 3.3 Поведение

1. Пользователь выбирает пресет → `style_prompt` копируется в поле `author_style`
2. Пользователь может отредактировать текст
3. При генерации глав/сцен `author_style` включается в системный промпт
4. Кнопка "Generate Sample" позволяет предварительно оценить стиль

## 4. Backend

### 4.1 Endpoint

```
GET /author-presets
Response: {
  "presets": [
    {
      "key": "pushkin",
      "name": "А. С. Пушкин",
      "language": "ru",
      "era": "XIX век",
      "description": "Лёгкий, ироничный стиль...",
      "sample": "Дубровский молча..."
    },
    ...
  ]
}

POST /author-presets/generate-sample
Body: {
  "preset_key": "pushkin",
  "logline": "История о молодом дворянине..."
}
Response: {
  "sample": "generated text in the selected style"
}
```

### 4.2 Интеграция с WriterPipeline

В `WriterPipeline` и `EditorAgent` — `author_style` используется как часть системного промпта:

```
You are a writer. Write in the following style:
{author_style}
```

Это уже частично реализовано через `project.author_style`. Нужно только добавить UI для выбора пресетов.

## 5. Расширяемость

- Пользовательские пресеты (сохранение в БД)
- Импорт/экспорт пресетов
- AI-анализ стиля: загрузить текст автора → система извлекает стилистические характеристики
- Смешение стилей: "80% Пушкин + 20% Чехов"
