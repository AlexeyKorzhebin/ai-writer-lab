# AI Writer Lab — План тестирования (E2E)

## Цель
Обеспечить стабильную работу backend, orchestration и UI через браузер.

---

# I. Smoke Test (UI базовая проверка)

1. Открыть главную страницу
2. Создать новый проект
3. Убедиться, что проект появился в списке
4. Перейти в проект
5. Создать новую главу

Ожидаемый результат:
- Нет 500 ошибок
- Страницы рендерятся корректно

---

# II. Генерация главы

1. Нажать Generate
2. Проверить:
   - Контент появился
   - Нет async / lazy loading ошибок
   - Нет зависаний

---

# III. Review → Edit Loop

1. Нажать Review
2. Убедиться, что вернулся текст рецензии
3. Нажать Edit
4. Проверить, что контент обновился

---

# IV. Produce High Quality (Orchestration)

1. Запустить Produce High Quality
2. Проверить:
   - Контент изменён
   - Нет async ошибок
   - Нет исключений SQLAlchemy

---

# V. Multi-Chapter Consistency

1. Создать 2–3 главы
2. Запустить Consistency
3. Проверить корректность анализа

---

# VI. Экспорт

- Скачать PDF
- Скачать DOCX
- Скачать EPUB

Проверить:
- Файл открывается
- Контент соответствует главам

---

# VII. Нагрузочный мини-тест

1. Создать 5–10 глав
2. Несколько раз подряд запустить генерацию
3. Проверить:
   - Нет утечек сессий
   - Нет MissingGreenlet
   - Нет зависаний

---

# VIII. Тестирование без LLM

Отключить OPENAI_API_KEY.

Ожидаемое поведение:
- Генерация возвращает "LLM not configured"
- Сервер не падает

---

# IX. Regression checklist

Перед каждым релизом:

- pytest зелёный
- Сервер запускается
- UI рендерится
- Генерация работает
- Review работает
- Edit работает
- Export работает
