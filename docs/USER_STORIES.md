# User Stories

## As an Author
- I want to generate a structured outline so that I can plan my book.
- I want chapters to maintain continuity with previous chapters.
- I want automatic review scoring to assess quality.
- I want the system to improve chapters iteratively.
- I want to manually edit content.
- I want to export my book in publishing formats.

## As a Technical Writer
- I want deterministic quality gates.
- I want structured review feedback.
- I want bounded iteration to control cost.

## As a Product Owner
- I want multi-agent coordination.
- I want extensibility for future agents.
- I want architecture documentation.
