---

# 1. Проблема водопадной модели в художественном процессе

Линейная модель:

Идея → Сюжет → Персонажи → Мир → Главы

не отражает реальный творческий процесс.

Писатель часто:
- меняет конфликт после написания нескольких глав
- переписывает арку героя
- добавляет или убирает персонажа
- изменяет финал, что требует переработки начала

Следовательно, Narrative Engine должен поддерживать:
- версионирование
- обратные изменения
- пересчёт зависимых элементов

---

# 2. Narrative Graph (вместо pipeline)

История рассматривается как граф зависимостей:

- Plot Spec
- World Spec
- Character Specs
- Location Specs
- Chapter Drafts
- Scene Variants

Изменение узла графа может требовать пересчёта зависимых узлов.

---

# 3. Что такое "Арка персонажа"

Арка персонажа (Character Arc) — это изменение героя на протяжении истории.

Она включает:

| Элемент | Описание |
|----------|----------|
| Начальное состояние | Кто герой в начале |
| Внутренний конфликт | Его страхи, сомнения, слабости |
| Ключевые события | Что ломает его прежние убеждения |
| Переломный момент | Момент трансформации |
| Финальное состояние | Кем он становится |

Пример:

Начало: Анна боится ответственности.
Перелом: Она вынуждена принять решение, от которого зависят другие.
Финал: Анна становится лидером.

Арка персонажа — это не просто набор сцен, а траектория изменения.

---

# 4. Почему это важно для AI Writer Lab

Если система знает арки персонажей, она может:
- проверять логичность поведения
- отслеживать эмоциональную динамику
- сигнализировать о нарушении мотивации
- предлагать развитие

---

# 5. Мультимодальное расширение (будущее)

Narrative Core может быть расширен слоями:

Text Layer
Visual Layer (иллюстрации сцен)
Audio Layer (музыка / атмосфера)
Poetry Layer (стихотворные версии сцен)

Каждая сцена может иметь несколько представлений.
